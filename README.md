# Contact Book

## Project Title

Contact Book - File-Based Contact Management System

## Description

A simple Python-based Contact Book application developed as part of the CodeOrbit Tech Python Programming Internship – Task 4.

The application allows users to add, search, update, delete, and view contacts. Contact information is stored permanently in a JSON file.

## Features

- Add new contacts
- Search contacts by name
- Update contact details
- Delete contacts
- View all contacts
- Stores name, phone number, and email
- Saves contacts in a JSON file
- Simple command-line interface

## Technologies Used

- Python 3.14.7
- VS Code
- JSON
- `json` module
- `os` module

## How to Run

1. Make sure Python is installed on your system.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python contact_book.py

5. Select an option from the menu.
6. Enter the required contact details.
7. The contacts will be stored in the `contacts.json` file.
